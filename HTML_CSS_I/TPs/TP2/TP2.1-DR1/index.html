Seletores

É possível estilizar textos HTML através de diferentes seletores. Veja:

1. Element

Element: seleciona todos os elementos de uma tag HTML específica, como p, h1, spam, etc.
Como exemplo, adicionei margem ao body e estilizei o seletor h3:

Texto estilizado pelo seletor h3 do tipo element

2. ID

O seletor ID permite alterar o elemento com o id correspontente. Ele é único em uma página, então deve ser usado para selecionar um único elemento. Usamos a seguinte notação: #nome-do-id.

Ainda estamos no mesmo parágrafo, e este é o meu nome dentro de uma tag span usando o id #nome-proprio

3. Global

Esse seletor é malandro, porque afeta TODOS os elementos. Basta alterar no CSS usando este símbolo: *
Geralmente ele é usado para redefinir as propriedades da página, zerando margens e paddings para manter consistência entre os navegadores. É possível alterar outras configurações nele, mas não é recomendado. Neste exemplo, zerei a margem e o padding.

4. Classe

O seletor de classe modifica todos os elementos da classe. As classes são criadas por nós, com palavras-chave arbitrárias, e são chamadas no css com um ponto. (.classe). Similar ao ID, mas pode ser usado mais vezes. Exemplo: Classe "texto-gritando" dentro de um seletor span
