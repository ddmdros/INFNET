Seletores

É possível estilizar textos HTML através de diferentes seletores. Veja:

1. Universal

Esse seletor é malandro, porque afeta TODOS os elementos. Basta alterar no CSS usando este símbolo: *
Geralmente ele é usado para redefinir as propriedades da página, zerando margens e paddings para manter consistência entre os navegadores. É possível alterar outras configurações nele, mas com muita cautela. Neste exemplo, deixei a cor da fonte padrão de todo mundo com um tom de cinza escuro.

2. Element

Percebeu que o título e subtítulo não seguem a regra do seletor universal? Usei o Element: que seleciona todos os elementos de uma tag HTML específica, como p, h1, spam, etc.
Como exemplo,estilizei os títulos h2 e h1 para deixá-los mais escuros.

3. ID

O seletor ID permite alterar o elemento que possui o id correspontente. Ele é único em uma página, então deve ser usado para selecionar um único elemento. Usamos a seguinte notação: #nome-do-id.

Este é o meu nome dentro de uma tag span usando o id #nome-proprio

4. Classe

O seletor de classe modifica os elementos de uma classe. As classes são criadas por nós, com palavras-chave arbitrárias, e são chamadas no css com um ponto. (.classe). Similar ao ID, mas pode ser usado mais vezes. Exemplo:

Classe "texto-gritando" dentro de um seletor span

5. Atributo

O seletor de atributo é ativado quando um elemento possui um atributo previamente definido. Esse seletor é legal porque ele é bem maleável, e pode ser usado de várias formas.

  • No CSS:
    • ul lu[type="A"]{color: blue;}: muda para azul a cor dos elementos li de uma lista não ordenada do tipo A
  • No HTML:
    • Adicionamos type="A" no li
