T2.2-DR2 Estilizando parágrafos

Publicado em: DD/MM/AA por Autor.

Estruture um documento HTML com 4 parágrafos contendo textos diferentes. Estilize cada parágrafo de forma única, sem repetição, alterando a visualização dos parágrafos no navegador. Use seletores para distinguir os parágrafos e estilize os seletores numa folha de estilos externa ao documento HTML.
