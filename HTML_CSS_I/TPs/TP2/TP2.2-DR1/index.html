1. Comecei estilizando todos os parágrafos com o seletor p, definindo-o com a cor cinza.

2. Em seguida, defino um parágrafo com a classe class="cursivo-italico". No HTML, chamo class="cursivo-italico" e no CSS chamo .cursivo-italico{}

3. Aqui, uso a classe class=cursivo-italico e o atributo data-type="sublinhado". No HTML, chamo class="cursivo-italico" e data-type="sublinhado", e no CSS só adiciono o [data-type="sublinhado]{}, pois já temos a classe cursiva definida.

4. Para finalizar, crio uma id única chamada "destaque". No HTML, chamo id="destaque" e no CSS chamo #destaque{} que cria um marca-texto amarelo pastel e muda a fonte para um cinza mais escuro que o padrão definido no seletor p.
