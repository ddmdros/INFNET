CSS - Dominando a estilização de elementos

Hierarquia

A hierarquia, ou Specificity, em inglês, diz respeito à ordem de importância dos seletores CSS quando mais de um seletor CSS é aplicado a um mesmo elemento.

A hierarquia é calculada a partir de um algorítimo com três categorias: ID, Classe e Tipo.

  • ID: inclui os seletores de ID, como #exemplo. Para cada ID, soma 1-0-0.
  • Classe: inclui seletores de classe, como .minhaClasse, seletores de atributo, como [type="exemplo1"] e pseudoclasses, como :hover. Para cada classe, atributo ou pseudo-classe, adiciona (0-1-0) ao valor da hierarquia.
  • Tipo: inclui seletores de tipo, como p, h1 e td, e pseudo elementos, como ::before e ::placeholder. Para cada tipo ou pseudoelemento, adiciona (0-0-1).
  • Universal: o seletor universal * não adiciona valor (0-0-0).

No final, os elementos recebem uma pontuação, que determinará a hierarquia, como:

  • (0-1-1)
  • (1-2-0)
  • (0-2-1)

Em que:

  • (1-2-0) > (0-2-1) > (0-1-1)

Pois

  • ID > CLASSE > TIPO

Proximidade

A proximidade se refere à posição dos elementos no HTML e à forma como seletores mais próximos, como filhos diretos, têm prioridade sobre regras mais genéricas.

Importância

Compreender como o efeito cascata do CSS funciona é fundamental para poder trabalhar bem com ele. Sem esse conhecimento, uma pessoa desenvolvedora pode se ver perdida, tentando atribuir efeitos e sem entender o porquê da sua folha de estilo não funcionar. Além disso, essas características hierárquicas existem para garantir maior consistência e legibilidade às páginas web.
